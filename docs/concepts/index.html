Why artifacts

GitHub Actions can open an artifact uploaded with actions/upload-artifact@v7 and archive: false directly in the browser — but only formats the browser renders natively (standalone HTML, images, markdown). So previews must be self-contained HTML: inline your CSS/JS, use data URIs for images.

A non-zipped artifact is keyed by its file basename, so mayfly renames same-named files (a.html, a-2.html) to keep them distinct.

Lifespan & cleanup

Artifacts expire after 90 days (the GitHub default). A daily workflow deletes preview/* branches idle for 90 days, matched to that retention. Hand-made branches are never touched.

Access control

Previews and the Pages site live in your repo, so visibility follows the repo. Make it private (Enterprise: set Pages visibility to private) and only authenticated collaborators can open the URLs.

URLs are not stable (artifacts)

An artifact preview URL contains the run and artifact ids, both minted per run — so re-pushing yields a new URL. keep → Pages is the way to a stable URL.
