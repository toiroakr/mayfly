    🦋 mayfly

    Ephemeral HTML hosting via GitHub Actions artifact previews — and this documentation site is hosted by mayfly itself.

    mayfly gives generated HTML (e.g. what an AI/agent produces) a browser-viewable URL without it becoming part of a codebase you merge. Throwaway previews live as artifacts that vanish after 90 days; the pieces worth keeping are promoted to GitHub Pages — like the pages of this very site.

    ModeCommandLives
    Throwawaymayfly pushartifact, gone in 90 days
    Keepmayfly keephere, on Pages (stable)
