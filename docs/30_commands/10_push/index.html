mayfly push

Publish files as throwaway browser-viewable previews and print their URLs as JSON.

mayfly push [-b <branch>] -f <file> [-f <file> ...] [--open]

Behaviour

  • Commits the files in one commit to a branch (auto-generated preview/<ts>-<rnd> if -b is omitted), via the GitHub API.
  • The Preview workflow uploads each file as its own archive: false artifact.
  • mayfly waits for the run, then maps each file to its artifact URL.
  • Same-basename files are renamed (a.html → a-2.html) so each stays distinct.

Options

FlagMeaning
-b, --branchTarget branch (reuse to update the same preview)
-f, --fileFile to publish (repeatable)
--openOpen the first preview URL in your browser
-m, --messageCommit message
-r, --repoTarget repo owner/name

Output

{
  "branch": { "name": "preview/...", "url": ".../tree/preview/..." },
  "files": [
    { "source": "/tmp/report.html", "name": "report.html", "url": ".../artifacts/456" }
  ]
}

stdout is JSON only; progress goes to stderr, so mayfly push -f x.html | jq works. For fire-and-forget, background it: mayfly push -f x.html > out.json 2>/dev/null &.
