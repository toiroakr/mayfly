mayfly list

List the live throwaway previews (the preview/* branches) with their latest run and per-file URLs.

mayfly list

Output

{
  "previews": [
    {
      "branch": "preview/20260612-...",
      "updated": "2026-06-12T06:35:05Z",
      "run": ".../actions/runs/123",
      "files": [ { "name": "report.html", "url": ".../artifacts/456" } ]
    }
  ]
}

Useful for seeing what's still alive before it expires, or for re-opening a preview URL.
