Workflows

The repo ships five GitHub Actions workflows. All are hand-written, pin actions by commit SHA, use persist-credentials: false, and request least-privilege permissions.

WorkflowTriggerDoes
preview.ymlpush of **.html (excl. docs/**)detect changed HTML → upload each as an artifact → comment the URLs on the commit
keep-preview.ymlPR touching docs/**.htmlbuild a preview of the kept page and comment it on the PR before merge
pages.ymlpush to default branch under docs/**generate pages.json (the doc index) and publish docs/ to GitHub Pages
cleanup.ymldaily scheduledelete preview/* branches idle for 90 days (default branch untouched)
zizmor.ymlpush/PR touching workflowsstatic security analysis of the workflows themselves (zizmor)

An integrated repo (via mayfly integrate) gets trimmed variants: mayfly-preview.yml (push to mayfly/*) and mayfly-cleanup.yml.
