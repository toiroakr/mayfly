mayfly delete

Delete preview branches early (they would otherwise auto-expire after 90 days).

mayfly delete -b <branch> [-b <branch> ...]
mayfly delete --all-previews

Behaviour

  • -b is repeatable to delete several branches at once.
  • --all-previews deletes every preview/* branch.
  • The default branch is always refused.

Output

{ "deleted": ["preview/20260612-...", "preview/20260613-..."] }
