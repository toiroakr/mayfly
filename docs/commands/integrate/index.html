mayfly integrate

Add throwaway previews to an existing repo without forking. Run it inside that repo.

cd your-repo
mayfly integrate            # --force to overwrite existing files
git add .github && git commit -m "Add mayfly previews" && git push

What it scaffolds

FileRole
.github/workflows/mayfly-preview.ymlOn push to mayfly/* branches, upload each HTML as an artifact
.github/workflows/mayfly-cleanup.ymlDelete mayfly/* branches idle for 90 days
.github/mayfly-previewA separate, repo-local CLI (not the full mayfly)

In an integrated repo, preview branches are namespaced mayfly/* (not preview/*) to avoid clashing with the host repo's branches.

The repo-local CLI

Post a local file's preview onto a PR — it pushes to a mayfly/* branch (CI builds the artifact), then comments the URL on the PR:

.github/mayfly-preview -f page.html --pr 123
.github/mayfly-preview -f page.html --pr 123 --target both   # comment | description | both
