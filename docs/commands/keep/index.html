mayfly keep

Promote a page from throwaway to permanent: open a PR that places it under docs/<path>; merging publishes it to GitHub Pages at a stable URL.

mayfly keep -p <path> -f <file> [-b <branch>] [--open]

Behaviour

  • Creates a keep/* branch off the default branch, places the file at docs/<path>, and opens a PR — it does not commit to the default branch directly, so the change goes through review.
  • The Keep preview workflow comments a preview of the page on the PR, so reviewers see it before merge.
  • Merging the PR triggers the Pages workflow, publishing docs/.

Source

A local file (-f path), or a file already on a preview branch (-b <branch> -f <name-on-branch>).

Options

FlagMeaning
-p, --pathDestination under docs/ (= the Pages URL path)
-f, --fileSource file (local, or name on -b)
-b, --branchSource preview branch (optional)
--openOpen the PR in your browser

Output

{
  "pr": { "url": ".../pull/7", "number": 7 },
  "path": "docs/design/index.html",
  "pages_path": "design/index.html",
  "branch": { "name": "keep/...", "url": ".../tree/keep/..." }
}
